# phantoms-ai-week3.
# تقرير ختام الأسبوع الثالث

خلصنا الأسبوع ده وجمعنا الأساسيات المهمة جداً في الـ Machine Learning، ودي خلاصة اللي عملناه:

1. إيه اللي اتعلمناه الأسبوع ده؟
- بدأنا في الأول بتنظيف البيانات وجهزناها صح عشان ندخلها في النماذج.
- جربنا أول نموذج تصنيف (Logistic Regression) وبعدها قارناه بنماذج تانية زي Decision Tree و KNN، وعرفنا ليه لازم نعمل Feature Scaling للبيانات عشان المسافات تتظبط في KNN.
- النهاردة بقى ختمنا بموضوعين مهمين:
  1. **الـ Unsupervised Learning:** جربنا خوارزمية K-Means عشان نقسم البيانات لمجموعات من غير ما نكون عارفين الـ Labels الأصلية، وطلعت النتايج مظطبة ومنطقية مع طبيعة البيانات.
  2. **ممشكلة الـ Data Leakage:** اتعلمنا ليه ممنوع نعمل Scaling أو تنظيف لكل البيانات مع بعض قبل ما نقسمها Train و Test، لأن ده بيخلي النموذج يشوف معلومات المستقبل وبيدينا دقة وهمية مش حقيقية.

 2. ملخص الشغل العملي
- طبقنا K-Means على بيانات الإيريس وشوفت إزاي المراكز (Centroids) بتتحدد وتتضبط لوحدها.
- جربنا كود فيه تسريب بيانات (Data Leakage) وطلع دقة غريبة، وبعدين صلِحناه بالطريقة الصح (إننا نقسم البيانات الأول وبعدين نعمل Scaling للتدريب بس) عشان نضمن إن النتيجة واقعية ونقدر نعتمد عليها.
